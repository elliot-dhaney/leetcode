**Problem Statement**

You are working in a ball factory where you have `n` balls numbered from `lowLimit` up to highLimit inclusive, and an infinite number of boxes numbered from 1 to infinity.

Your job at this factory is to put each ball in the box with a number equal to the sum of digits of the ball's number. Given two integers `lowLimit` and `highLimit`, return the number of balls in the box with the most balls.

 

Example 1:

```
Input: lowLimit = 1, highLimit = 10
Output: 2
```

Example 2:

```
Input: lowLimit = 5, highLimit = 15
Output: 2
```

Example 3:

```
Input: lowLimit = 19, highLimit = 28
Output: 2
```
